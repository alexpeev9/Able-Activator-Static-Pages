# Able Activator — static pages

A collection of standalone static pages for **[activator.bg](https://activator.bg/)**.

## What is Able Activator

**ABLE Activator** is a hands-on entrepreneurship program in Bulgaria. It helps ambitious people turn an idea into something they can launch — through workshops, mentors, and a community of founders.

The main program runs over several weekends. There is also a shorter **Weekend Activator**. Graduates can join **ABLE**, a community that promotes leadership and entrepreneurship in Bulgaria.

Official site: [activator.bg](https://activator.bg/)

## What this repo is

Design previews for the Activator site: landing pages, program pages, and Weekend Activator. They are static HTML pages, grouped in a simple catalog.

Browse them live: [able-activator.vercel.app](https://able-activator.vercel.app/)
